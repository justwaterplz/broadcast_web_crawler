CJ ENM, TVING, COM2US N 비교 · 2026-10-05 조사 기준

핵심 결론

TVING은 가장 풍부하고 구조화된 메타데이터를 제공합니다. CJ ENM은 상세 데이터 품질은 높지만 일반 자동수집 정책이 가장 큰 제약입니다. COM2US N은 접근은 쉽지만 작품 메타데이터가 제한적입니다.

사이트별 조사 결과

CJ ENM

정책 제한

카테고리와 상세 페이지는 HTTP 200으로 직접 열리지만 일반 User-Agent에는 robots.txt의 전체 차단 규칙이 적용됩니다. 공개 sitemap 수집은 가능하며 상세 페이지 대량 자동 순회에는 별도 허가가 필요합니다.

상세 페이지 데이터
작품명, 장르·채널, 방영 기간, 연출·극본, 출연진, 줄거리, 등장인물 설명, 포스터·스틸 이미지
Sitemap 데이터
상세 URL, 수정일, 이미지·영상·뉴스 메타데이터. 출연진과 상세 줄거리는 포함되지 않습니다.

TVING

수집 가능

콘텐츠 페이지는 로그인 없이 HTTP 200으로 접근되며 robots.txt는 일반 경로를 허용하고 /service/만 제외합니다.

상세 페이지 데이터
제목, 프로그램·회차 코드, 장르, 채널, 편성 요일·시간, 방영 기간, 크리에이터, 출연진, 등급, 전체 회차 수, 회차별 제목· 줄거리·방영일·재생시간, 예고·티저·하이라이트, 자막·DRM· Original 여부
추출 방식
DOM, JSON-LD, __NEXT_DATA__가 제공되어 이미지 분석 없이 추출할 수 있습니다. 영상 스트림은 수집 대상에서 제외합니다.

COM2US N

수집 가능

robots.txt는 /coming-soon을 제외한 일반 크롤링을 허용합니다. 카테고리에서 숫자 ID 기반 상세 URL을 열거할 수 있으며 대표 드라마·예능 페이지 접근도 성공했습니다.

상세 페이지 데이터
작품 ID, 한글·영문 제목, 대분류·세부 장르, 연도, 공개일, 선택적인 클라이언트·기간·장소, YouTube URL, 이미지 목록, 이전·다음 작품
제약
출연진, 배역, 제작진, 줄거리, 방송사·편성 정보가 없어 다른 출처와의 결합이 필요합니다.

수집 우선순위 제안

1순위 TVING, 2순위 COM2US N으로 전수조사를 진행하고, CJ ENM은 공개 sitemap 범위부터 수집한 뒤 상세 페이지는 공식 허가가 확보된 경우에 확장하는 구성이 적절합니다.

English summary

TVING offers the richest structured program and episode metadata. CJ ENM provides high-quality detail pages but restricts generic automated crawling, so collection should rely on public sitemaps or explicit permission. COM2US N is crawlable and easy to enumerate, but its records contain only basic project metadata.

이 문서는 독립형 HTML이며 외부 리소스 없이 열립니다. 웹 링크는 HTML 원본과 대부분의 PDF 출력 환경에서 클릭 가능한 상태로 유지됩니다.
